# Security

## Report a vulnerability

Do not open a public issue for a security problem.

1. Go to the [Security tab](https://github.com/getbeton/inspector/security) of this repository.
2. Click **Report a vulnerability**.
3. Give the steps to reproduce the problem and what an attacker can get.

## Scope

The code and the files in this repository. Beton has no hosted service now. Beton is not in active development, so a fix can take time. If you run this code, you own its security.
